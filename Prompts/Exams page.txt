Grading Configuration:
- GradeScale entity: configurable per school/academic year with fields { name, thresholds[] }
  Each threshold: { minPercent, maxPercent, grade, gradePoint }
  Example: [ { 90-100, "A+", 4.0 }, { 80-89, "A", 3.7 }, { 70-79, "B", 3.0 }, ... { 0-39, "F", 0.0 } ]
- Global MarksConfig: { maxDecimalPlaces: 2, roundingMode: "HALF_UP" }
- calcGrade(marks, totalMarks, gradeScale, marksConfig):
  1. percent = (marks / totalMarks) * 100
  2. Round percent to marksConfig.maxDecimalPlaces using marksConfig.roundingMode
  3. Match against gradeScale.thresholds to return { grade, gradePoint }
  4. If result.isAbsent == true → skip numeric grading, return grade = "N/A", marks = null

Summary section showing:
  - Total Marks: sum of totalMarks across included exams
  - Total Obtained Marks: sum of marksObtained (Absent treated as 0)
  - Overall Percentage: sum(marks_obtained * exam_weight) / sum(total_marks * exam_weight) * 100
    (If no weightage is set on any exam, fallback to simple: totalObtained / totalMaxMarks * 100)
  - Overall Grade: map Overall Percentage against the active GradeScale (same thresholds as individual exams)
  - Rank in class: absolute rank by Overall Percentage descending within the class-section
    Ties: students with identical percentage share the same rank (dense ranking); next rank skips accordingly
    Percentile: optional display = ((totalStudents - rank) / totalStudents) * 100

Exam Inclusion Criteria:
- Include only exams where exam.status == "Completed"
- Exclude exams with status Draft or Scheduled
- Absent exams: isAbsent == true → marks treated as 0 in totals; grade shown as "N/A" in the row

Weightage Handling:
- exam.weightage (optional % from exam creation) participates in Overall Percentage when set
- If any exam in the set has a weightage, all exams must use weighted formula; exams without explicit weightage default to weightage = 1.0

Filter Behavior:
- Filter options: by subject, by exam type, by date range
- Applying filters recalculates summary metrics (Total, Percentage, Grade, Rank) based on the filtered subset only
- Rank recalculates within the same filtered context for all students in the class
